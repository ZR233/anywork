# 演进与验证

## 统一读取，不建立第二保存链路

存储保证见 [Studio 存储](../../../../design/17-studio-storage.md)；
先理解现有 Session、HistoryStore 与 writer 的职责，前端不自行协调 RAM 与 SQLite。
不要为界面增加第二保存队列、定时器或历史数据库。

若领域采用“完成事实先可见、后可靠保存”，说明以下提交点而非笼统声称“已完成”：

1. 一次准备不可变载荷，整批加入可查询集合，再发通知。
2. 同一批交给既有 writer，与其执行事实、checkpoint、身份索引和附件屏障保持原事务保证。
3. 真实提交确认后才推进连续持久化前缀并回收对应 pending。

失败保留已接纳事实并显示原保存故障；条数和字节都计入可靠预算，
超限按既有安全点背压，不丢最旧条目或无限增长。可见而未可靠保存的 RAM 在崩溃时可能丢失，
不能同时承诺“不等可靠写入即可确认可见”与“崩溃后零丢失”。
数据库事务提交、WAL checkpoint 与机器断电保证也不能混为一谈。

### 有前提的交接证明

以下只适用于不可变记录、稳定身份及统一读取所有者，并非所有可变缓存的通用算法：

- 短临界区捕获代次、可见上界 H 和请求范围内有界的 pending 引用，不克隆全表。
- 锁外建立**新的**数据库读快照，只读不超过 H 的同一范围，合并、去重并校验身份／载荷一致性。
- 若 writer 在捕获后回收，读取仍持有不可变引用；若在捕获前回收，提交已完成，
  后开的数据库快照能读到。两处同时命中只返回一次。

复用捕获前的旧 SQLite 快照会破坏该证明；跨 await 重新解析到另一代 owner 也会混入不同数据。
读取须保持原 owner 与代次，重置则显式拒绝。必要数据库 I/O 不等于等待新事实落盘；
不要在 Dart 加二次查询或查询前强制 flush 来掩盖交接缺口。

## 迁移保证语义，不只是建表

使用现有 SeaORM migration 序列与事务边界。除字段存在外，还要验证真实主键、唯一性、
比较语义和游标回填次序，防止分页批次静默遗漏。旧迁移的校验只要求该历史阶段应存在的结构，
不能因新增表而让早期步骤提前依赖未来格式。

回填、校验、schema 与迁移完成记录应保持既定原子性，失败保留可重试现场；
所用版本的事务能力和连接必须实查，不假定每种后端都会自动包事务。
内容升级与生命周期准备分开，冷历史读取不为迁移启动模型或工具。
缺少来源、时间或因果顺序就保留未知，不能用当前时间、零值或最后修订伪造首次完成。

旧格式只在明确迁移边界解码；受影响消费者、映射、生成物和文档同步切换后移除旧入口。
不要为删除展示旧路径而误删执行恢复、审查或资源修复仍使用的事实。破坏性接口调整不授权清库，
现役数据和隔离旧目录的边界继续遵循存储契约。

## 用契约减少补偿逻辑

- 不先换页面库解决状态协议问题；先核对已有组件公开能力，薄适配只承载领域语义。
  具体页面库不由本技能指定，候选方案和自研授权仍遵循项目选型规则。
- 对不可变、有序且只从两端扩展的集合，可用首尾边界投影代替任意重排与全表 diff；
  有可变或重排需求时不能机械套用。展示身份稳定不等于任意高度变化下像素位置不变。
- 一页数据即使全部并入已有展示分组、未增加可见元素，原始数据游标仍应推进；
  不按卡片数判断是否到达历史起点。
- 共享不可变引用不要求每层复制正文；逻辑冻结却引用可覆盖资源，也不能称为零复制优化。
  惰性构建只减少已构建 widget，不自动淘汰 controller 已加载的数据。
- 分开度量页面数据、传输缓冲、正文暂存、媒体缓存与可靠队列。
  明确条目、帧、字节、token 的单位，不能以一项预算冒充全部有界。

## 选择最小充分证据

使用 `test-quality` 的已有证明分析，按变化选择边界，不把下表变成每次必跑清单：

| 风险 | 有效反例或证据 |
| --- | --- |
| 单一写入与冻结 | 外部集合被修改、重复同身份冲突，不能改变已接纳事实 |
| 路由与草稿 | 拒绝离页、等待中修改草稿、旧操作完成后新页面不跳转 |
| 消费与背压 | 前批未接纳而后帧 ready，确认不越界；超窗口快照无自锁 |
| 生命周期 | open 尚未完成即关闭、正在等 credit 时取消、回调重入，真实 owner 全部收束 |
| 存储交接 | writer 提交／回收与读快照交错，不漏不重；故障不伪装保存 |
| 迁移 | 非空旧库、跨批重复或比较语义错误、回填失败回滚，用户数据保留 |
| 呈现 | 分页与事件交叠、分组边界改变、只影响实际变化的消费者 |

用受控屏障或阶段信号证明交错，不以 sleep、压力循环未失败替代。
需要证明生产者被 credit 阻塞时，应观测其已进入等待，而不只看消费者暂停。
测试替身提供环境，不重新实现被测归约器。静态分析不证明交互，
widget 不证明 native 句柄和持久化，单平台／模拟对端不证明跨平台／真实供应商兼容。
构建、生成和原生观察使用 `flutter-studio-build`，复用未受影响结果，不惯性叠加全量检查。
