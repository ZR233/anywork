# 项目优先的会话侧边栏设计

状态：已采纳并落地重构。基于 Flutter 桌面界面与 [19 - Studio 界面与交互](../19-studio-ui.md) 的暹罗猫（Siamese）色系规范，以项目优先树形结构取代早期的全局新建会话入口及项目／会话平铺分区。

![侧边栏与添加项目流程](../assets/project-sidebar-concept.png)

## 1. 设计依据与参考

早期布局中 `StudioLayout.sidebarWidth` 固定为 `232px`，窗口宽度低于 `900px` 时直接收缩为 `60px` 纯图标栏。重构后采用可拖拽调宽的项目树与保留完整文字层级的窄屏抽屉，配合紧凑单行排版与按需悬停详情，直观呈现会话的项目归属与运行状态，避免单纯依赖文本截断省略。

交互分层参考了 [Claude Code Desktop](https://code.claude.com/docs/en/desktop) 对并行会话、项目目录及本地／SSH 远程环境的清晰区分，以及 [Cursor Cloud Agents](https://cursor.com/docs/cloud-agent) 的独立执行环境组织方式。本文中的项目树结构、尺寸断点与分步向导均为本产品的工程设计约定；文中所称“远程环境”特指本产品已有的 SSH 远程连接能力（详见 [22 - SSH 远程连接与工作区](../22-ssh-remote.md)）。

## 2. 侧边栏结构与视觉层次

- **顶部搜索与筛选**：顶部固定“项目与会话”搜索框，下方紧跟`全部`、`进行中`、`待处理`三态过滤标签。搜索与过滤始终保留匹配会话所属的项目父节点并仅临时展开匹配分支，清空搜索或过滤条件后恢复此前的展开状态。
- **两级项目树结构**：“项目”分栏标题右侧常驻`＋ 添加项目`入口。项目为一级节点，会话为二级节点；支持同时独立展开多个项目，切换当前选中会话不会强制折叠其他已展开项目。
- **项目行元素与环境消歧**：项目行依次显示展开／折叠箭头、文件夹图标、项目名称、本地／SSH 环境标识及常驻`＋`按钮（无障碍标签为“在〈项目名〉中新建会话”，点击区域与项目折叠热区互不干扰），右侧更多菜单提供项目管理操作。完整物理路径收纳于只读悬停提示中，支持从更多菜单一键复制；同名项目通过环境标识与路径提示消歧，项目行自身不主动探测远端主机在线状态或 Git 仓库状态。
- **会话行排版与工作树标识**：会话行相对项目行缩进 `16px` 并附带轻量纵向引导线。标题采用当前 `TextTheme` 的紧凑单行尾部省略；右侧预留固定宽度的状态与操作区，确保鼠标悬停或键盘聚焦浮现操作按钮时不会挤压标题造成文字跳动。完整标题、所属项目、运行环境、权威会话工作区路径、执行状态与活跃时间集中在按需悬停详情中展示，不在列表内常驻双行辅助文本。当会话采用独立 Git 工作树模式（`workspace_mode = worktree`）时，右侧状态区额外展示工作树图标与本地化说明（普通本地目录会话不展示）。
- **选中高亮与运行态指示**：选中会话采用拿铁底色配左侧细蓝竖条，所属项目仅加粗字重，避免父子两级同时大面积高亮造成视觉干扰。排队、执行中、等待工具、取消中与关闭中状态统一显示小型旋转进度圈；等待用户交互确认显示静态待处理图标；执行失败显示错误图标。每行严格读取自身权威目录状态（Directory Status），不借用当前选中会话的忙碌状态；所有状态图标均配备文字说明与无障碍语义标签，且在系统开启“减少动画”偏好时自动切换为静态指示。
- **会话操作菜单与悬停隔离**：会话行内仅保留`置顶`切换与`更多`菜单两项操作（置顶作用域限定在所属项目内部；按钮在鼠标悬停或键盘聚焦时显现，触控环境下常显）。悬停详情采用 Flutter 官方 `Tooltip.richMessage` 实现，保持只读且忽略指针事件（Ignore Pointer），不拦截行点击或操作按钮；更多菜单采用独立的 `MenuAnchor` 与 `MenuItemButton` 实现，不将操作菜单嵌套在悬停详情内，也不引入自定义悬停定时器或开合互斥状态机。更多菜单提供`重命名`、`项目内置顶`、`复制路径`、已有的`打开工作区`入口及`归档`。
- **当前归档确认与工作区保留**：根会话归档与子智能体最终关闭保持独立。`归档`对空闲、运行中及工作区故障会话均可用，不借用执行或打开工作区的阻塞状态禁用入口；真正的全局或目标数据访问故障仍按权威准入处理。更多菜单的模态确认告知将停止会话树的活动工作，保留历史、工作区及未提交内容；取消确认无副作用。关闭与保存失败展示实际错误，不伪装归档成功；工作树缺失或暂时不可读不阻止归档。从归档列表恢复只恢复目录与历史可见性，不重建工作树或切换目录，原工作区故障仍保护执行。
- **恢复页的分支观察**：消费后端清理授权与检查结果；当前分支可空，只有 `inspection = available` 且分支为空才显示 detached，检查失败时显示未知，不伪装为创建分支或 detached。未知变更状态如实展示，缺失或不可读资源提供重试检查与原路径，不提供后端未授权的清理动作。
- **待接入的归档强制清理确认**：后续归档接线及其独立失败验收完成后，归档确认明确授权 `force=true`，告知将最终关闭成员、释放资源并删除本会话及子智能体明确拥有的工作树；未提交、未跟踪、ignored 文件及无其他引用的 detached 提交可能丢失，历史、附件与 Git 分支保留。local 根也可能有子工作树，不得省略警告。取消确认无副作用；关闭、保存或清理失败显示真实错误并允许接续剩余工作，不能发布完整成功。恢复目录不撤销最终关闭或重建工作树。此文案与对应 Driver 只在生产接线完成后启用，不因子智能体最终关闭已落地而提前承诺归档清理能力。物理资源契约见 [12.5](../12-collaboration.md#125-git-工作树worktree生命周期与故障恢复)。
- **排序、分页与底部固定区**：项目按“已置顶优先、最近活跃次之”排序；每个展开项目初始展示最近 8 条普通会话及该项目内的全部置顶会话，超出部分通过`查看更早会话`按每页 20 条分页加载（支持失败重试），且列表排序不随流式输出的每个词元（Token）抖动。折叠起来的项目行仍在右侧保留待处理交互计数。侧边栏底部以留有左右边距的细分隔线划出纵向固定操作区，放置`已归档`与`设置`入口（左对齐图标与文本，整行可点击并具备悬停与焦点反馈；归档视图激活时以浅色背景高亮，设置入口保留版本更新提示点）。

## 3. 响应式布局与人机工程指标

| 可用窗口宽度（逻辑像素） | 侧边栏与主工作区布局策略 |
| --- | --- |
| `≥ 1200px` | 侧边栏默认宽度 `336px`，支持在 `300px–440px` 范围内拖拽调整并持久化记忆；右侧会话阅读列遵循 [19 - Studio 界面与交互](../19-studio-ui.md#197-视觉主题与布局) 的最大阅读宽度与居中留白约定 |
| `960px–1199px` | 沿用用户偏好的侧边栏宽度（默认 `336px`），同时按实际窗口宽度动态约束，确保扣除分隔条后仍为右侧对话区保留至少 `600px` 净宽 |
| `< 960px` | 收起固定侧边栏，通过顶栏菜单按钮呼出覆盖式项目抽屉（宽度取 `min(360px, 窗口宽度 - 24px)`），抽屉内保留完整文字树结构，选中会话后自动收起 |

当系统字体放大导致固定侧边栏无法容纳有效文字时，自动提前切换为覆盖式抽屉模式；手动折叠／展开侧边栏的入口在所有宽度下常驻可用。窄窗口下打开分步向导弹窗时自动转为可滚动的全屏步骤页，固定页头与底部主操作栏，并在软键盘弹出时自动滚动确保当前聚焦输入框可见。

人机工程与快捷键约定：

- **点击热区与对比度**：桌面端交互按钮最小点击热区为 `32×32px`，触控环境最小为 `44×44px`；常规正文文本与背景的对比度不低于 `4.5:1`。
- **键盘导航与快捷键**：项目树支持方向键展开／折叠与上下移动、`Enter` 键选中会话、`Tab` 键进入行内操作按钮；侧边栏分隔条支持键盘微调宽度与一键恢复默认宽度。全局快捷键 `Ctrl+K`（macOS 为 `Cmd+K`）聚焦搜索框，`Ctrl+N`（macOS 为 `Cmd+N`）在当前明确选中的项目下新建会话（若当前无任何项目则直接呼出“添加项目”向导）。

## 4. 添加项目完整向导流程

1. **选择项目位置类型**：点击侧边栏`＋ 添加项目`打开单实例分步向导弹窗，第一步选择`本地项目`或`远程项目（SSH）`；未选择前`继续`按钮保持禁用。
2. **本地项目分支**：调起操作系统原生文件夹选择器（取消选择则退回第一步）。选定文件夹后由后端校验目录可达性并注册项目，默认以文件夹名称作为项目显示名；若所选规范化路径已存在于项目列表中，则直接定位并展开该既有项目，不创建重复条目；目录无权限或访问失败时停留在当前步骤并提供重新选择入口。
3. **远程项目分支——主机选择与管理**：展示从用户 `~/.ssh/config` 解析出的 SSH 主机列表、顶部搜索框及同行`新建远程配置`按钮。每条主机配置显示别名（`Host`）、用户名、主机地址、端口、已配置认证方式标签（如密钥、密码）及当前连接状态（未经本次会话实际探测通过前不标记为在线）。位于 `anywork` 受管块内的条目提供行内`编辑`与`删除`操作（删除需二次确认并同步清除系统凭据库中关联的密码）；用户手写的原生 `~/.ssh/config` 条目仅作只读展示。若当前无任何 SSH 配置，则直接展示空状态引导与新建按钮。
4. **远程连接探测与按需密码认证**：选中目标主机并点击`连接并选择目录`。客户端首先以非交互方式探测 `ssh-agent` 与本地私钥，免密认证通过后直接进入远程目录浏览页，不弹出密码输入框。仅当免密探测失败且远端服务器明确通告支持 `password` 或 `keyboard-interactive` 认证时，才自动弹出密码输入对话框（支持选择将密码保存至系统凭据库或仅在当前进程会话内生效）；若远端服务器仅允许公钥认证，则在原地提示需配置私钥或启动 `ssh-agent`，不展示无效的密码输入框。连接期间展示加载进度，失败时支持原地重试、编辑受管配置或退回重选主机。
5. **新建或编辑受管 SSH 配置**：表单收集连接别名（写入 `~/.ssh/config` 的 `Host` 字段，创建后不可重命名）、主机地址、端口（默认 `22`）、用户名、可选密码（采用与模型供应商 API 密钥一致的系统凭据库 `Preserve` / `Replace` / `Clear` 语义存储于 `ssh:<alias>`，绝不写入 `~/.ssh/config` 明文）及可选私钥路径。表单提供即时字段格式校验；保存后将公开连接参数写入 `~/.ssh/config` 的 `anywork` 受管块并同步更新系统凭据库，随后可直接在向导内继续发起连接。
6. **远程目录浏览与校验**：连接成功后进入远程目录选择页，顶部明确标识当前连接的服务器别名与地址，提供路径输入框、返回上一级、前往／刷新按钮与子目录列表。仅当目标目录内容加载校验成功后才允许进入下一步；手动修改路径文本后必须重新验证，禁止借用旧路径的验证通过状态提交新路径。普通文件不可作为项目根目录，空文件夹允许选定。
7. **确认项目信息与幂等提交**：提交前在确认页汇总展示项目名称（默认取目录名，支持修改）、运行环境标识与完整规范化路径。点击提交期间锁定按钮防止重复提交；若后端返回失败则保留已选服务器与目录上下文供原地重试；若相同 SSH 主机与规范化路径的远程项目已存在，则直接定位打开该既有项目。
8. **完成落位与空状态聚焦**：后端确认添加成功后关闭向导弹窗，在侧边栏自动展开并滚动定位至新项目，主工作区显示“还没有会话”空状态引导，同时将键盘焦点置于该项目行的`＋ 新建会话`按钮上（不自动创建空白会话；待用户点击新建后进入该项目的输入草稿态）。

## 5. 导航返回、错误恢复与状态同步边界

- **对话框路由与焦点恢复**：添加项目主向导及子级模态框（新建／编辑主机、密码输入、删除确认）均采用标准 Flutter 对话框路由管理，步骤间后退完整保留已选选项与表单输入，关闭弹窗后将键盘焦点归还给发起按钮。远程目录浏览页支持按 `Escape` 键关闭；提交请求在途期间保持弹窗显示直至收到明确结果。
- **SSH 主机指纹核验**：首次连接未知主机或检测到远端主机公钥指纹变化时，严格复用真实 SSH `known_hosts` 信任确认流程并展示完整指纹信息供用户核对，绝不静默自动信任。
- **断连降级与历史可读性**：当远程项目的 SSH 连接断开时，侧边栏完整保留该项目及其名下历史会话，项目行展示断连标识与一键重连入口；依赖实时远程连接的操作在界面上说明不可用原因，但历史会话列表与已落盘消息时间线仍保持正常点选阅读，不一并禁用。
- **权威目录状态与增量刷新**：目录分页查询、归档与恢复、项目重命名及界面布局偏好均由 Studio 运行时提供权威状态，通过 FRB 与 HTTP 共享同一套协议契约。归档操作保留的热状态覆盖尚未落盘的冷数据行，待异步落盘完成后再从热集合中淘汰；后台工具刷新不会为已退役的会话实例重新发布恢复错误。
- **分页窗口与过滤稳定性**：每个项目首页返回 8 条普通会话并附带配置中记录的置顶会话，后续分页每页 20 条并按会话身份去重；已归档列表按当前已打开项目分组组织（已移除的项目需重新打开原目录后方可查看并恢复其归档历史）。侧边栏宽度及项目／会话两类置顶列表通过 `Settings` 乐观并发控制（CAS）持久化，每类置顶上限为 64 项。目录变更事件按修订版本（Revision）原位更新已加载的分页窗口，保持当前滚动位置与已展开分页不变；仅当事件确实改变了当前搜索或状态过滤的成员资格时，才定向重新查询受影响项目（自动合并在途请求并保留旧列表直至新结果返回）。搜索与过滤仅约束可见成员集合，不冻结已展示行的元数据——可见行的运行状态、标题与工作区标识持续消费权威目录流实时更新，确保运行进度圈在任务结束时立即停止，无需等待下一次手动搜索。
