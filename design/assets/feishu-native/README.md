# 飞书机器人原生界面验收证据说明

飞书机器人接入的桌面原生界面验收截图统一作为 [PR #138](https://github.com/ZR233/anywork/pull/138) 的附件归档，不随源码仓库分发。附件覆盖机器人总览、机器人详情、窄窗口自适应与超长名称排版等场景，具体验证范围见该 PR 的版本说明。验收过程中产生的原始截图、Flutter Driver 状态快照与运行日志均保存在 Git 忽略的本地 `target/manual-gui/` 证据目录中。

早期在 Linux / Xvfb 环境下采集的七张合成平台界面截图已移出源码树（历史版本仍可通过 Git 提交记录查阅）。本地模拟界面截图不能替代新版 Windows 原生界面或真实飞书客户端的端到端验证；任何静态截图均不能单独证明附件完整性、入站输入幂等去重、状态持久化或子进程回收，验收结论必须结合对应的结构化运行记录共同判定。

## Markdown 与流式输出的 Linux 隔离观察证据

针对 Markdown 消息与 CardKit 流式卡片输出的[固定版本界面截图与范围说明](https://github.com/ZR233/anywork/tree/fa4351f19248a110898e09a233657ad739900ebb)存放在独立的证据分支中，不进入产品源码分支或发行安装包。该组证据涵盖首次配置七项默认权限说明、同一回复的流式生成中状态与完成态渲染，由真实的 Flutter 桌面端、FRB 桥接层、Studio 运行时配合隔离脚本化模型与飞书模拟对端（Peer）经由 Flutter Driver 采集，且退出关闭报告确认为 `clean`、`persistence=drained`、`issues=[]`。

上述截图展示的是 `anywork` 本地桌面界面，而非飞书客户端渲染画面；CardKit 流式更新协议与故障恢复的完整性仍须结合独立协议观察记录（`bots_protocol_observe`）核实，不得仅凭本地界面截图外推为真实飞书企业租户环境兼容性已通过。
