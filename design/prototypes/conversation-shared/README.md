# 会话概念稿共享模块

此目录仅维护浏览器概念稿，不是 Rust、Client 或 Flutter 的运行时契约。所有会话、命令输出、费用及模型字段都是模拟数据，按钮不会执行真实命令或调用供应商。

- `preview.css`：作用域样式、主题角色、阅读列与状态布局。
- `fixtures.js`：时间线快照、工作组、正文与问题，以及可重复播放的事件序列；各实时场景都是同一事件序列中的命名帧（`at`）。
- `state.js`：每个挂载点独立的状态控制器，统一管理时间线、唯一状态栏内容、草稿、决定和播放生命周期。
- `components.js`：时间线和状态栏共用的 Markdown、工作组、工具详情、回执、终态行、压缩完成行及停靠面板。
- `preview.js`：页面装配、局部视图状态、事件绑定和详情查看。

页面通过相对路径的普通 `defer` 脚本按上述顺序加载，使用 `data-conversation-preview` 挂载，`data-scenario`（或 URL 查询参数 `?scenario=<id>`）指定初始场景，`data-controls="false"` 隐藏演示工具。各挂载点拥有自己的控制器、详情窗口和定时任务。

状态栏（输入区上方）只允许「思考中」、当前工作组、文本输出、上下文压缩四种互斥内容；时间线只收录已结束的内容。Runtime 仍按 [原子完成契约](../../26-timeline-content.md) 逐条发布不可变完成事实，展示分组则由前端决定：

- 新工作组先在状态栏中插入，成员逐个加入；已完成的成员以对勾留在组内，运行中的成员继续计时，不逐条进入时间线。
- 成员全部完成而下一条信息尚未到达时，工作组仍留在状态栏，标题切换为「思考中」。下一条若仍是思考或工具，继续并入本组。
- 出现需要新分组的信息——正文开始、提问、轮次结束、停止或失败——时，状态栏中的整组一次移入时间线，随后状态栏切换到对应内容或收起。时间线不出现运行中或会继续增长的组，新工作组也不会接到时间线里的旧组后面。
- 完整文本可靠结束后整段进入时间线；压缩成功为单行回执。重复交接不重复追加，时间线条目不随计时或后续流变化。

状态栏工作组标题由成员状态派生：有运行成员时为「工作中」，否则为「思考中」；折叠时在标题后显示当前运行步骤，展开后由成员行展示，不重复显示。右侧计数为「已完成 · 进行中 · 耗时」。成员行用对勾或旋转图标表达状态，只在失败／停止时附加文字。时间线中的工作组摘要为「工作了 N 秒」加按类型计数的图标，以及失败／停止步数。

四种状态共用旋转的活动图标，运行中成员图标同样旋转，动画不依赖演示是否播放；系统开启减少动态效果时显示静态图标。新轮次、首段正文到达前，以及完整正文移交时间线后仍在等待模型响应时，只显示「思考中」与耗时，没有展开入口。等待本身不生成空工作组或空正文条目，期间停止或失败仍保留相应终态记录。「正在压缩」同样采用单行展示，仅保留活动图标、状态文字与耗时。

执行失败与停止时，状态栏中的工作组连同未完成成员（标记为失败或已停止）整组移入时间线，并分别形成独立的 timeline 终态元素，默认折叠，复用工具组的摘要行、字级、颜色、间距与展开导轨；展开后查看本次活动与具体原因。正文和工具组保留原始内容及成员结果，不重复附加整轮终态提示。压缩失败／停止使用相同元素，成功压缩仍为单行完成记录；失败后的压缩重试位于上下文详情中。

工作组内容渲染由同一组件负责，`live` 与 `history` 仅决定外层、标题、状态图标、计时和动作。提问是新分组信息：此前的工作组先移入时间线，问题在待回答时使用停靠面板（状态栏收起），回答后使用只读回执；敏感回答不会进入时间线、复制内容或详情。

输入区始终复用同一个纯图标主按钮：运行中无内容为停止方块，停止后无内容为继续播放图标，有文字／附件时为发送上箭头，普通空闲且无内容则禁用。运行中或停止后有内容时，发送动作同时继续执行。按钮不显示文字或悬停文字提示，操作语义仅通过无障碍名称表达。继续只由显式点击主按钮发起，空输入回车不触发恢复。输入区不再放失败／停止提示，也不额外添加继续按钮。

浏览器原生 `details`、`dialog`、表单和文件选择器负责对应交互。Markdown 使用固定版本 Marked `18.1.2`，再经 DOMPurify `3.4.17` 清洗；图标沿用已有原型的 Lucide `1.17.0`。这些脚本通过 CDN 加载，首次打开需要联网，不提供另一套解析器或图标回退实现：

- [Marked 文档与安全说明](https://marked.js.org/)
- [DOMPurify 用法](https://github.com/cure53/DOMPurify)
- [Lucide 浏览器用法](https://lucide.dev/guide/lucide)
- [HTML 交互元素契约](https://html.spec.whatwg.org/multipage/interactive-elements.html)

交付检查使用本地静态文件、Playwright Chromium 和真实浏览器截图；不以此替代原生 GUI 或供应商验收。一次性验证脚本和截图存放于本会话产物目录，不提交到此目录。
