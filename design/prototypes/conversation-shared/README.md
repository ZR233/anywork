# 会话概念稿共享组件模块（`conversation-shared`）

此目录维护浏览器端统一会话交互概念稿的唯一共享实现（与账号概念稿的 `accounts-shared/` 对齐），不是 Rust、Client 或 Flutter 的运行时契约。所有项目、会话、命令输出、费用及模型目录字段均为本地模拟数据，按钮不会执行真实命令或调用外部供应商。

本概念稿的“当前工作组保留已完成成员、真实边界及终态齐备后整组交接”已由 [#316](https://github.com/ZR233/anywork/issues/316) 恢复为生产目标，正式合同见 [26](../../26-timeline-content.md)。Rust 原 owner 增量维护展示快照，原件完成即保存；Flutter 一冻结块一卡，展开沿稳定块引用按需读取。模拟器的人工 seal、补造终态及互斥阶段不能复制到生产；真实产品允许 closing 工作组与正文并存，概念稿不能替代原生验证。

## 1. 组件化入口与零复制挂载结构

四个桌面外壳与会话概念稿入口页均为约 26 行的纯声明式 HTML 薄壳，按固定顺序加载同一套共享侧边栏组件（`../sidebar-shared/`）与会话共享模块（`../conversation-shared/`），不在单页内复制侧边栏、顶栏、时间线、状态栏或输入框代码：

- [项目与会话侧边栏共享组件](../project-sidebar/index.html)：`data-page="sidebar"`，默认场景 `sidebar-overview`。聚焦侧边栏顶层动线优化（`新建会话 → 实时搜索 → 三态紧凑筛选 → 项目树 → 非项目会话 → 双栏底栏`）、温暖拿铁底色与左侧眼眸蓝选中竖条、会话行尾四列定轴状态槽（`置顶 · 工作树 · 运行状态 · 更多菜单`，状态变化图标零位移）、重复标签与对勾降噪、跨边界二级「打开方式 ▶」原色徽标子菜单、已归档恢复、添加本地/SSH 项目向导及右侧宽度拖拽手柄。
- [新会话起始页与工作区输入布局](../session-start/index.html)：`data-page="start"`，默认场景 `local`。聚焦统一的新会话起始页——直接点击侧栏「新建会话」与在项目行点击「+」均进入同一新会话页，外层环境栏左侧展示并可点击切换新会话开启在「无项目」、支持实时模糊搜索的「已有项目」列表或「新建项目…」，右侧配置 `本地目录 / 新建工作树` 与子智能体分发，内层复用统一输入卡并支持首条请求四阶段准备交接。
- [会话运行时输入框与配置锁定](../session-composer/index.html)：`data-page="composer"`，默认场景 `running-locked`。聚焦会话创建后外层创建栏退役、顶栏冻结徽标投影、运行期选择器加锁与就地原因提示、并发拟稿、唯一主按钮六态切换、模型不可用自愈、机器人统一路由及子智能体只读底栏。
- [会话时间线与实时状态栏](../live-status/index.html)：`data-page="session"`，默认场景 `workgroup`。聚焦实时状态栏四种互斥内容、工作组边界整组移交时间线、流式 Markdown 阅读跟随、分步问答停靠面板与独立折叠终态回执。

共享模块职责划分：

- `../sidebar-shared/sidebar.css` 与 `../sidebar-shared/sidebar.js`：独立封装的 `StudioSidebar` 共享侧边栏组件与宿主应用矢量徽标（`VS Code` / `Zed` / `终端`），在全部会话概念稿页面单实例复用并与 `ConversationController` 双向同步，同时通过底栏「设置」与账号概念稿的「返回聊天」构成跨页闭环。一级菜单、二级「打开方式 ▶」子菜单与只读悬停详情卡统一挂载于窗口级 `.sb-portal`，避免被侧栏滚动区裁切。
- `preview.css`：暹罗浅色主题 Material 3 作用域样式（绑定 MDUI `2.1.4` 主题色板与排版变量，使用 `:where(.cv-preview)` 零特异度基线避免覆盖组件类）、全域无轨道自动隐藏胶囊滚动条（静止完全隐藏，滚动中 `.is-scrolling` 或悬停滑块时浮现，`850ms` 后自动淡出，消除原生白底轨道与上下箭头）、统一应用外壳（承载可调宽 `--sb-width` 侧栏宿主与上下文顶栏）、起始页双层同心创建台、会话居中阅读列、实时状态栏、统一 `PromptComposerCard` 与锁定状态视觉、问答停靠区、子智能体只读底栏及右侧 M3 配置可配性检查器。
- `fixtures.js`：项目目录（本地 Git、SSH 远程 Git、普通非 Git 目录）、非项目独立会话、工作模式、按账号分组的模型目录（含无推理强度模型）、主/子智能体目录、时间线快照、可重复播放的事件序列，以及按生命周期划分的 **33 个统一场景**（侧边栏组件 5 个、创建期 7 个、运行期输入与锁定 8 个、时间线与状态栏 13 个）。
- `state.js`：每个挂载点独立的 `ConversationController` 状态机，统一管理起始页到已建会话的四阶段准备交接、权威配置可配性判定（`getLockState`）、唯一主操作槽位六态派生（`getPrimaryAction`）、锁定原因横条（`explainLock`）、时间线与状态栏播放、停止收束过渡、待决问答期间的草稿暂存及主/子智能体视图切换。
- `components.js`：时间线和实时状态栏共用的安全 Markdown、工作组（`live` 与 `history` 共用同一成员内容渲染）、工具详情查看、只读问答回执、独立折叠终态行、上下文压缩回执及分步问答停靠面板。
- `composer.js`：统一的锚定浮层菜单管理器、会话顶栏（创建期冻结徽标、`n 个智能体` 切换与行内唯一停止入口、复用 `StudioSidebar` 原色应用徽标的打开工作区菜单）、在起始页外层环境栏与会话底部停靠区之间**复用同一 DOM 实例**的 `PromptComposerCard`（切换场景或输入过程中保持焦点与选区不丢失）、四阶段环境准备卡片与子智能体只读底栏。
- `preview.js`：可选统一页头/跨页视图切换标签/页脚装配（`data-page-chrome="true"`）、`StudioSidebar` 与双阶段视图挂载、右侧实时配置可配性矩阵刷新与对话框事件绑定。

挂载约定：页面加载 MDUI `2.1.4`、`../sidebar-shared/sidebar.css` 与 `../conversation-shared/preview.css` 样式后，通过相对路径的 `defer` 脚本按 `../sidebar-shared/sidebar.js → fixtures.js → state.js → components.js → composer.js → preview.js` 顺序加载，使用 `data-conversation-preview` 挂载，`data-page="sidebar|start|composer|session"` 指定默认视角与场景分组优先级，`data-page-chrome="true"` 渲染统一 M3 页头与分段标签栏，`data-scenario`（或 URL 查询参数 `?scenario=<id>`）指定初始场景，`data-controls="false"` 隐藏右侧演示检查器。

## 2. 会话生命周期配置锁定与输入框交互规则

概念稿完整呈现会话从创建草稿到运行期的配置冻结与动态锁定边界（详见 [起始页与会话输入生命周期设计](../../concepts/session-start-layout.md) 与 [19 - 桌面界面规范](../../19-studio-ui.md)）：

- **创建期一次性冻结项退役至顶栏**：所属项目/非项目归属、会话工作区模式（`local` 本地目录 / `worktree` 新建工作树）与子智能体分发策略在根会话创建瞬间永久冻结。进入已建会话后，起始页外层暖米色创建环境栏整体退役，输入区收敛为单层暖白输入卡；已冻结的工作区与分发策略投影为会话顶栏只读标签（不堆叠锁图标）。
- **运行期等宽零位移不可交互态**：输入卡底栏保留「工作模式 · 主智能体模型 · 思考强度」三联选择器原位不动：
  - 轮次运行中、上下文压缩中或正在停止收束期间，三项选择器全部转为简洁不可交互态（省略锁图标与边框底色，保留一致的触发器内边距与下拉箭头几何占位，呈柔和置灰无悬停高亮态，悬停 Tooltip 说明原因，状态切换 `0px` 位移）。
  - 图工作模式（如「任务 · 实施」）处于活动阶段但当前轮次已空闲时，**仅将工作模式置为原宽不可交互态**以保护运行中的状态图与已批计划，**主智能体模型与思考强度保持可正常切换**，在下一轮生效。
  - 所选模型不支持推理强度（如 `DeepSeek-V3.2`）时，仅「思考强度」单独以定宽不可交互态显示 `—`。
  - 外部机器人托管会话将模型与强度区合并为只读不可交互的「由机器人统一设置」标签。
- **路由不可用阻断与原地换模自愈**：当前绑定模型被停用或账号失效时，保留原模型名并在选择器旁显示告警按钮，卡内提示阻塞原因并禁用发送/继续，不自动改选其他模型；同时保持模型选择器可点击，切换至任一可用模型后立即解除阻塞。
- **并发草稿编辑、图片缩略图弹层与定宽唯一主操作圆钮**：主会话运行期间文本框与附件添加始终保持可编辑；剪贴板粘贴或本地选入的图片在输入区上方以紧凑视觉缩略图排布（右上角独立移除，点击缩略图弹出模态大图预览层，支持多图 `← / →` 切换、`1:1 原图 / 适应窗口` 缩放及 `Esc` 关闭归还焦点）。右下角固定 `34×34px` 的唯一主圆钮按权威状态在六种形态间原位零位移切换：空闲空草稿禁用 `↑`、可提交草稿海豹棕 `↑`、运行中空草稿中性停止 `■`（聚焦按 `Esc` 亦可停止并保留草稿）、运行中或已停止且有草稿时海豹棕发送并继续 `↑`、停止收束期间禁用旋转 `◌`、已停止保留未消费继续点且无草稿时海豹棕继续 **`▶`**（空输入按回车不触发恢复）。
- **待决问答草稿暂存、四列定宽智能体目录与子会话只读底栏**：待决提问展开分步问答停靠面板时，未发送草稿与附件自动暂存并在回答或跳过后原样恢复；顶栏 `28px` 等高控件与 `会话智能体目录` 四列定宽网格（对勾 · 标题与路由 · 右对齐状态 · `26×26px` 固定停止槽位）确保主/子会话切换与子任务停止时列表与顶栏严整不跳动；查看子智能体会话时整个输入区替换为只读状态底栏。

## 3. 实时状态栏与时间线视觉参照

概念稿演示「思考中」、工作组、流式文本和上下文压缩的主题与交互。下列模拟阶段保留为旧视觉参照，不是 #316 修订后的执行时序或验收标准；其中“工作组先留状态栏、等成员终态再移交”的规则已经被 [26](../../26-timeline-content.md) 替代。正式产品在可靠正文开始时立即冻结旧组的真实观察，迟来结束在新组形成新行，工作组统一放在 Timeline 工作区，正文区独立；不通过改模拟器断言来证明生产通过。真实 item、顺序和归属仍由 Studio 原 owner 确定。

以下仅描述现有模拟器：

- 新工作组先在状态栏中插入，成员逐个加入；运行中的成员显示圆形进度并继续计时，已完成的成员切换为对应类目的语义图标（思考、读取、命令、搜索、修改、等待）留在组内，不逐条进入时间线。
- 初次显示的实时和历史 Work 均默认折叠，用户主动展开后保持其意图。实时状态栏全态（思考中、工作组、正在输出、正在压缩上下文）共享固定 `32×32px` 前导图标槽、`10px` 间距、`15px` 单行标题与右对齐 `12.5px` 等宽数字“执行了 N 分 N 秒”（`min-height: 34px`），状态切换只原位替换图标与文案而不抖动：等待/思考、待交接态以及顶栏展示思考摘要时统一采用暹罗趴卧摇尾猫动态 SVG，仅当本组尚无思考摘要且存在运行中 `command`/`exec` 时顶栏切换为 `20×20` 圆形进度（组内运行中的 `command`/`exec` 成员行始终显示 `14×14` 圆形进度），流式正文输出采用纸笔分层书写动态 SVG，上下文压缩采用经典圆角档案包＋交错拉链齿＋滑动拉环动态 ZIP 图标。现工作组一旦产生思考摘要，其折叠单行标题即持续展示本组最新单行 Markdown 思考摘要（替换「思考中」、运行指令等阶段文案，随组内新思考摘要即时更新，不跨工作组串用）；上方时间线中的已结束工作组标题保持「工作了 N 分 N 秒」（缺时长回退「工作记录」）。时长从本组第一条信息创建开始，包含组内等待，真实整组封存后冻结，不是累计活动耗时或整轮耗时。正式数据与生命周期合同见 [26.8](../../26-timeline-content.md#268-flutter-状态栏与唯一组件集合)。模拟器只为该呈现提供静态交互参照，不作为生产计时或生命周期证明。
- 当前成员列表及展开后的终端输出自然增高，实时组由外层工作组阅读区统一纵向滚动；历史组由主时间线滚动，内部不另设纵向滚动区。
- 思考成员默认单行：概要优先（支持单行 Markdown），仅有正文时显示“思考了 2 分 5 秒”等真实耗时；存在正文才提供原生 `details` 展开，没有正文的概要不可展开。`reasoning-variants` 场景并列展示概要与正文、仅概要、仅正文三种输入。
- 成员全部完成而下一条信息尚未到达时，工作组仍留在状态栏，继续展示本组最新思考摘要（尚无思考摘要时显示「思考中」）；下一条若仍是思考或工具，继续并入本组。
- 出现真实后继边界——正文开始、独立状态/回执、轮次或来源结束、停止或失败——时，状态栏中的整组一次移入时间线，随后状态栏切换到对应内容或收起；分组与边界由 Studio 投影决定，不按模拟阶段枚举。时间线不出现运行中或会继续增长的组，新工作组也不会接到时间线里的旧组后面。
- 完整文本可靠结束后整段进入时间线；压缩成功追加单行完成回执。执行失败与正常停止分别形成独立的默认折叠终态行，停止采用中性图标与文案，不渲染为错误。敏感问答回答在摘要、展开回执与复制内容中统一隐藏。
- 当前正式分页以 Rust 冻结的 DisplayBlock 为单位，一块一卡，不切开组或扫描成员找头；原子完成立即保存，但不逐项增长历史尾组。Flutter 按稳定 block_id 保持呈现与展开意图，布局补载沿块页继续，展开通过原有界成员窗口读取。逆序终态、可靠空正文退役、纯附件及后台独立 Single 都须由当前生产链验证，不能用模拟器时序或内部成员索引行推导展示块一定是 Work。

## 4. 外部依赖与本地预览检查

浏览器原生 `details`、`dialog`、表单和文件选择器负责对应交互。Material 3 组件与进度指示采用固定版本 MDUI `2.1.4`；Markdown 使用固定版本 Marked `18.1.2`，再经 DOMPurify `3.4.17` 清洗；图标沿用固定版本 Lucide `1.17.0`。这些脚本通过 CDN 加载，首次打开需要联网，不维护另一套解析器或图标回退实现：

- [MDUI 2 文档与组件契约](https://www.mdui.org/zh-cn/docs/2)
- [Marked 文档与安全说明](https://marked.js.org/)
- [DOMPurify 用法](https://github.com/cure53/DOMPurify)
- [Lucide 浏览器用法](https://lucide.dev/guide/lucide)
- [HTML 交互元素契约](https://html.spec.whatwg.org/multipage/interactive-elements.html)

交付检查使用本地静态服务与无头浏览器真实渲染截图核验布局、图标替换与交互状态，不以此替代原生 GUI 或真实供应商验收。一次性验证脚本与验证截图存放于本会话临时产物目录，不提交到源码树。
