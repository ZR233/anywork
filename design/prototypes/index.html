核心交互稿

会话时间线与实时状态栏

共享 conversation-shared · 13 个场景

工作组与实时状态栏主交互入口

状态栏承载当前工作组：成员逐个插入，完成的打勾留在组内；出现正文、提问或轮次结束等新分组信息时整组一次移入时间线。时间线只收录已结束内容。

整组交接 单步与连续播放 工具输出详情

实时文本与上下文压缩流式阅读与压缩回执

正文开始时上一工作组已整组入时间线，流式 Markdown 正文在状态栏输出并支持手动阅读时暂停跟随；上下文压缩以单行展示并在完成后追加时间线回执。

流式 Markdown 暂停跟随 手动与自动压缩

分步问答停靠区待决提问与交互

提问到达时此前的工作组整组移入时间线，状态栏收起并在输入区上方展开分步问答停靠面板，支持单选、多选、补充说明与敏感输入。

分步问答 敏感输入保护 跳过或提交

问答回执与终态记录回执 / 停止 / 失败

回答后在时间线生成默认折叠的只读回执（敏感回答自动隐藏）；停止或执行失败时生成独立折叠的终态行，输入区复用唯一纯图标主按钮切换停止、继续与发送。

只读问答回执 独立折叠终态 唯一主操作按钮
