此记录是有限样本的实验结果，不是产品性能保证。最初两项独立复验的工具回传文本明显减少，但总 token、费用和耗时没有一致改善。后续提示词配对实验中，首次 Lua 调用成功为 4/6 → 6/6；最终正常交付且独立验收通过均为 5/6，不能据此宣称整体任务成功率或费用已稳定改善。各阶段及失败分别保留如下。

## 任务和验收

调优组为三种固定的小型 Python 项目，各两次配对并交替运行顺序：跨文件发票折扣修复、重复 SKU 库存聚合、SQLite 会话失效边界修复。外部验收脚本在模型工作区之外；项目测试允许模型补充，但不能代替独立验收。

复验项目在首次真实 Lua 运行前另行冻结，未参与提示词调优：Decimal 账目聚合，以及审计记录游标分页。双方各运行一次；无额外重复，不能据此推断统计显著性或跨项目普遍收益。

调优修复了默认提示词仍将 exec 描述为 shell 的冲突，明确 Lua 长字符串、命令调用和结果筛选方式。首个 Lua 运行还暴露了生产 writer 从模型上下文查找嵌套调用的缺口；修复后用相同生产投影/关闭/冷读链做先失败、后通过的回归，再重跑该任务。原失败记录保留。

## 隔离证据与局限

扫描实际请求，嵌套调用均没有独立的 function_call_output。正常 Lua 运行中有 47 个子调用的生产历史记录；45 个没有被脚本主动输出的完整任务身份均未出现在后续实际请求中，另外两个由脚本主动返回。真实 Thread 测试另以专用中间数据标记验证未选择内容不会进入模型上下文，并验证完整参数、结果、失败、媒体投影在可靠存储和重开后仍可查询，不重放命令。

证据保留于 `/home/zhourui/.codex/worktrees/5337/pure-lang/target/lua-exec-observe`：`protocol/` 保存冻结任务、基线、费率、汇率和源码/二进制身份；`runs/` 保存隔离数据、关闭结果和独立验收；`ledger/` 保存真实请求、usage 与预算账本；`metrics.json` 给出逐次汇总。私有网关配置不随源码提交。首轮阶段参考费用合计 **¥0.549081**，144 次模型请求，含失败与重试。

结果只覆盖 Linux、此端点和这些小型项目；不等同于 GUI 人工验收，不外推到 Windows/macOS，也不承诺长项目的总成本收益。Lua VM 每次重新创建，命令子调用等待终态；需要持续 stdin 交互的程序不能依赖旧的 shell exec 任务回执流程。

可用 `cargo run --locked -p pl-studio-runtime --features live-tests --example exec_orchestration_observe -- MANIFEST.json` 运行观察入口；manifest 指定新的 `home`、`workspace`、`output`、`prompt_file`、Responses 网关 `base_url` 和 `timeout_seconds`，凭据由 `PILOT_MODEL_API_KEY` 环境变量提供。此入口为隔离观察创建配置，目录必须是专用实验目录。不要指向用户现有 Studio home。

后续修正保留了相同协议，补齐文件资源重选的父子来源、程序级并发上限及未处理失败后停止派发的行为，并迁移桌面验收。按用户要求删除额外的 256 次子调用门限、600 秒超时上限、64 KiB 展示上限和 4 KiB 错误原件截断，恢复 Lua 自带垃圾回收入口，并允许技能读取在原 owner 的 CAS 管理下串行嵌套。默认期限和展示预算不变，调用方可传正值调整；VM 内存、并发及可靠保存配额继续生效。上表是修正前精确提交的测量，不冒充后续提交的性能结果。

后续额外复验及最终 head 的验证终态在 PR 中补充，并继续使用同一预算账本；上表和本阶段费用均保留原始观测范围，不以修复重跑覆盖失败。

## 首次执行提示与回执契约调优

首轮轨迹中，13 次 Lua 运行有 11 次真正进入程序，只有 3 次首个程序成功；首次失败主要是把 shell 文本当 Lua、表和调用括号闭合错误。两个目录准备失败和 writer 失败仍保留，不能将其排除后冒充全部运行通过。

调优提交 `5fc63587ffd00ede6a8aee16af61511919fab6b1` 补齐可直接运行的 shell 调用、参数形态和返回字段；明确默认预算、Lua 长字符串、顶层 Plan 审批条件，并提供 Serde 支持的 `json.decode` / `json.encode`。SDK 复用工具已有 output schema，MCP 在存在时将 structuredContent 交给 Lua，原始协议仍完整保存。语法与未知绑定给出针对性诊断；错误的默认字符串只包含 message，完整原件仍可用 err.output 查询。正常启动且完整捕获的非零命令退出作为 exitCode 数据交给 Lua，原子调用历史仍是 Failed；权限、启动、取消、超时、捕获和归档失败不被转换为成功，不重放命令。

实验前冻结三个新 Python 项目：嵌套配置覆盖、CSV Decimal 聚合、URL 路径与查询编码。项目测试原件不变，外部独立验收保留在模型工作区之外；每项各两次配对、交替顺序。调优前生产提交为 `30a0ec33af0bb4c88a412a06ad395dfbf4ebd170`，二进制 SHA-256 `9713c0a74b58a745a3baedd867f167fc6063e4d62b4fa15b846b351dd505ef9d`；调优后为 `5fc63587ffd00ede6a8aee16af61511919fab6b1`，SHA-256 `39cdd7fc52c19344a3aee46576dd2b96d91c9f41671614c269eac1e911f23a93`。
