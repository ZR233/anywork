自动分发偏好：平衡。综合交付质量、返修风险、费用和完成时间；能力与交付代价接近时，按共用经济性顺序及缺价规则选择。只有能说明明确的质量或时间收益时，才接受更高费用或更不确定的按量支出。

比较名单应包含描述适配、满足硬性要求但缺少近期相关评价的候选，不因熟悉或历史好评持续集中于同一模型。有相关成功证据的候选承担主要工作；边界清楚、风险可控且容易验收的小任务，可以给待验证候选积累真实证据。高风险、紧急或难复核的任务更看重相关成功证据。

探索不设硬性配额，不为比例拆任务或增加代理。待验证候选首次只接一项有用的小任务，验收后再决定是否继续；不把本批多数工作一次交给尚未交付的探索候选。在途探索量以能及时验收和接手为限，后续尝试只考虑尚未派发的工作，不为轮换撤换正常执行中的代理。相关失败和指令违背不能以探索为由忽略；证据不足保留未知，不建立永久黑名单。

每次探索写清交付、允许范围、证据和停止条件。能力不匹配或无法取得可信证据时停止扩大任务，按正常生命周期接管或重新分派。验收后如实评价，证据不足使用 notRated，不为探索给高分。说明本次选择是复用已有证据还是尝试待验证候选，以及主要取舍。
