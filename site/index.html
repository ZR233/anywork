真实工作台一眼看清

不套浏览器外壳，所有会话调度、模型流式推理、工具编排与持久化均在单进程原生运行时内完成。

为什么把日常活交给糊来帮

围绕真实工程协作打磨核心环节：谁来干、按什么规矩干、怎么验收沉淀、人不在电脑前如何指挥。

分工协作，按实测评价自动选模

内置只读摸底的探索者、动手改码验证的执行者、在独立 Git 工作树并行干活不弄乱当前目录的工作树执行者，以及独立挑错的审查者。开启自动选模后，系统结合价格、免费/包月额度、首字延迟、输出吞吐率与本机历史评分，按经济、平衡、快速三种偏好挑选最合适的模型；任务收尾后自动后台复盘，把有效经验整理为项目级 Skill。

可视化编排工作模式，支持零费用预演

日常问答用「简洁模式」即问即答；复杂工程切到「任务模式」，严格按“规划 → 更新设计 → 委派实施 → 核对成果 → 整体验收”推进，先出计划、你批准后再动手，发现设计偏差还能沿返工边退回。你也可以在流程图画布上自由拖拽阶段与跳转条件，保存前静态编译检查，并支持不调模型、不花钱的离线运行预演。

飞书扫码接入，手机随时远程派活

在设置页扫码创建或连接飞书自建应用，直连飞书官方长连接接口，无需额外部署公网服务器或安装 Node.js 网关。谁能触发完全由本机掌控：陌生私聊仅生成待批准配对请求，群聊需单独授权并显式 @ 机器人；人在路上发条飞书消息，桌面端的 AI 团队就能在关联项目里干活并把结果发回手机。

多家模型混搭与本地 / SSH 一致工具箱

像打开本地文件夹一样直连 SSH 远程服务器目录，读写补丁、全文检索、LSP 代码导航、终端命令、联网搜索、MCP 扩展以及内置 Word / Excel / PowerPoint 办公技能开箱即用；实时展示上下文水位、缓存命中率与会话费用估算。

三步开启第一个任务

  1. 1
    添加模型账号

    打开「设置 → 账号 → 添加账号」，选用内置模板填入 API Key，或使用订阅账号登录、接入本地模型服务。

  2. 2
    选择本地或 SSH 远程目录

    直接开启非项目新会话，或在左侧栏添加本地项目目录、通过 SSH 打开远端服务器工作区。

  3. 3
    选定模式，说出想法

    按需选择「简洁」或「任务」工作模式、是否新建独立 Git 工作树，以及子智能体自动选模偏好，即可交由团队推进。
